# Palm92 Five-Tool Operating Playbook

## 1. NotebookLM: decide
Create one notebook per commercial decision. Add only trusted sources, Palm92 constraints, customer evidence and existing product documentation. Ask for a specific buyer, costly problem, testable offer, evidence required, first ten prospects and a 14-day validation plan. Verify recommendations against cited sources.

## 2. Apify: discover demand
Use permitted public-data collection to identify repeated questions, content patterns and buyer language. Record source, date, engagement signal and relevance. Create original Palm92 content rather than copying. Respect platform terms, privacy, copyright and data-protection obligations.

## 3. Astro and Vercel: convert
Each landing page answers: What is it? Why should I trust it? What happens next? Use one primary call to action. Preview every change before production and measure meaningful outcomes such as qualified enquiries and pilot conversions.

## 4. n8n and ChatGPT: support
Retrieve answers only from approved help documentation. Answer routine questions, ask clarifying questions when necessary and escalate failed guidance, uncertainty, frustration, suspected bugs and sensitive matters with the complete context.

## 5. GitHub: protect and recover
Version code, websites, workflows, help documents, prompts, tests and configuration templates. Use branches, pull-request review, automated checks, preview deployments and tagged stable releases. Restore service before diagnosing a failed production release.

## Execution order
Start with the current bottleneck. For Palm92 this means the Astro and Vercel conversion site, protected in GitHub, followed by grounded support, evidence-based research and controlled content discovery.
